# TLD Companion by XAHTEP

**Неофициальный компаньон для The Long Dark — Survival Mode.**

TLD Companion — проект офлайн-помощника для игроков The Long Dark, ориентированный на удобный доступ к игровой информации через браузер.

### Возможности

- Каталог игровых предметов.
- Русский и английский языки.
- Поиск предметов и игровой информации.
- Интерфейс, вдохновлённый атмосферой The Long Dark.
- Дальнейшее развитие справочника и инструментов для выживания.

## English

**TLD Companion** is an unofficial offline browser-based companion for The Long Dark, focused on Survival Mode.

The project aims to provide convenient access to item information, bilingual search, and survival reference tools in an interface inspired by the game's atmosphere.

Public builds will be available in the [Releases section](https://github.com/XAHTEP-BNA/TLD-Companion/releases).

**Status:** Active development. The first public release is in preparation.
