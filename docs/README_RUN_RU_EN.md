# TLD Companion — Beta

RU: распакуйте ZIP полностью в отдельную папку и откройте index.html в Chrome или Edge. Приложение работает без интернета;внешние ссылки открываются только по вашему действию. Для копирования используйте кнопку Copy/копирования;при отказе браузера готовая строка остаётся доступной для ручного выделения.

EN: extract the entire ZIP into its own folder and open index.html in Chrome or Edge. The application works offline;external links open only when selected. Use Copy for commands;the prepared command remains manually selectable if the browser rejects clipboard access.

Windows PC browser companion for The Long Dark Survival Mode. Unofficial fan project,not affiliated with Hinterland. See PATCH_NOTES_RU.md / PATCH_NOTES_EN.md and licenses/. Do not overwrite your earlier installation when keeping a comparison copy. Browser-local saves may differ between browsers/launch origins.
